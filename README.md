# Text to Speech Converter

A minimalist standalone application that streams synthetic vocal voice-overs from written text.


# Note :
* **The audo file which are being converted are saved locally.**

## ⚙️ Features
* **Subdirectory Control**: Generates text audio fragments explicitly inside an isolated `audios/` folder.
* **Modern Design**: Clean CSS-animated background canvas with responsive glass layout controls.
* **Multilingual Options**: Out-of-the-box support for translation tracking across 5 major dialect families.

## 🚀 Installation & Launch
1. Initialize your localized execution virtual environment inside your terminal workspace:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. Download all required framework extensions:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the development environment interface routing layer:
   ```bash
   python main.py
   ```
4. Access your application directly within your browser window target at `http://127.0.0.1:8000`.
